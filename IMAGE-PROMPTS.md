# SNET Networks — Image prompts (professional, realistic)

Style: high-end commercial advertising imagery — the kind used by Safaricom, Airtel or Starlink campaigns.
Realistic product renders and real-world scenes, cinematic lighting, SNET blue colour grade, clean space for the website text.

How to use:
1. Paste one prompt into ChatGPT per message.
2. Save the result into `public/photos/` with **exactly** the file name shown (`.png`, `.jpg` or `.webp`).
3. Redeploy — the site swaps it in automatically.

If an image comes back with words, logos or brand names, reply: **"Same image, remove every bit of text, numbers and logos."**
