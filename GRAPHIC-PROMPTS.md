# SNET Networks — 2D graphic prompts

The site already shows built-in 2D graphics. To replace any of them with a richer ChatGPT-made graphic:

1. Paste the prompt into ChatGPT (one image per message).
2. Download it and save it in `public/photos/` with **exactly** the file name shown (`.png`, `.jpg` or `.webp` all work).
3. Redeploy — the site swaps it in automatically.

Every prompt uses the same style so the whole site matches. If a result has words or logos in it, reply:
**"Same image, but remove all text, numbers and logos."**
